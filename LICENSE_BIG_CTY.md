# Big CTY — Amateur Radio Country Files

This application includes the **Big CTY** database (`cty.dat`), created and maintained by **Jim Reisert (AD1C)** at [Country Files (country-files.com)](https://www.country-files.com/).

Copyright (c) Jim Reisert AD1C. All rights reserved.

The country files are provided for free to the amateur radio community by Jim Reisert, AD1C, for use in logging programs and digital mode applications to identify DXCC entities, CQ zones, ITU zones, continents, and approximate geographical coordinates.

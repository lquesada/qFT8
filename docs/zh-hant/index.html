qFT8 獎狀

內建於應用程式，適用於業餘無線電操作者和收聽者（SWL）：為你通聯或聽到的模式、波段、DXCC 實體和網格方格授予星級，隨進度逐步填滿的獎狀，以及可分享的成就。

應用程式會根據你自己的日誌自動產生證書：無需申請，無需寄送。共有兩個計畫：HAM（已確認的通聯）和 SWL（你收聽到的電台）。

HAM 星級：14 種模式（FT8, LQ8, FT4, JS8, JT65, Q65, CW, SSB, FM, RTTY, PSK, SSTV, DV, JTTY）中的每一種和 13 個波段（160 公尺至 70 公分）中的每一個，在 1, 5, 10, 50, 100, 500, 1000, 5000, 10000, 50000 個不同電台時最多可獲得 10 顆星。DXCC 按 1 至 300 個現有實體（共 340 個）最多 10 顆星，網格方塊按 1 至 2000 個最多 10 顆星。每個通聯過的模式與波段組合再加一顆星：共 472 顆。

SWL：為你收聽到的電台提供同樣的星級，按業餘模式分組、按業務（廣播、時間信號、信標、海事、航空、氣象）以及 DXCC 實體和網格方塊計算。

常見問題

qFT8 是什麼？

qFT8 是一款免費的業餘無線電程式，支援弱訊號數位模式、摩斯電碼、電傳打字、圖片和語音。它可在 Android 手機和平板、iOS、Windows、macOS 和 Linux 上執行，並可透過任何瀏覽器控制。它沒有廣告，也無需帳號。作者是 Luis Quesada Torres，HB9IPH，解碼器和編碼器均為自行從零編寫。

Android 上有哪款好用的 FT8 應用程式？

qFT8 是適用於 Android 6.0 及更新版本手機和平板的完整 FT8 電台：用一條 USB 線連接電台，qFT8 會自動辨識並自行設定 CAT 和音訊，無需電腦，也無需介面盒。它可收發 FT8、FT4、FT2、LQ8、JS8、WSPR 等模式，在完整 AUTO 下回應 CQ，透過網際網路或 GPS 保持時鐘準確，在即時世界地圖上顯示所有電台，並把每個 QSO 記錄到你選擇的服務中。螢幕關閉後仍可持續運作。免費，無廣告，無需帳號。

我可以在 Windows、Mac 或 Linux 電腦上執行 FT8 嗎？

可以。qFT8 可在 Windows（64 位元和 32 位元，也可從 Microsoft Store 取得）、所有 Mac（Apple Silicon 和 Intel）以及 Linux（Intel/AMD 和 ARM，包括 Raspberry Pi）上執行，模式、電台和功能與 Android 版相同。本頁的下載均免費。

有適用於 iPhone 和 iPad 的 FT8 應用程式嗎？

qFT8 也可在 iPhone 和 iPad（iOS）上執行。iPhone 或 iPad 無法透過纜線控制電台，因此它透過電台的 VOX，或透過可根據音訊觸發電台發射的音訊介面來控制電台發射。

哪些電台可以搭配 qFT8 使用？

70 多種電台型號可透過 USB 隨插即用，包括 QRP Labs QMX、QMX+ 和 QDX，Icom IC-7300、IC-705 和 IC-9700，以及 Yaesu、Kenwood、Elecraft、Xiegu、Lab599、GuoHe、FlexRadio 和 (tr)uSDX 的電台。其他任何電台可透過 VOX 音訊線或 DigiRig 使用，RTL-SDR 等 SDR 接收機可用於接收。

我能用手機搭配 QRP Labs QMX 或 Icom IC-7300 嗎？

可以。用一條 USB 線把 QMX、QMX+ 或 IC-7300 連接到 Android 手機或平板：qFT8 會找到電台，透過 CAT 讀取和設定頻率，並經同一條線收發音訊。無需音效卡或額外介面。電腦上同樣可用。

qFT8 支援哪些模式？

FT8、FT4、FT2、LQ8、JS8、WSPR、CW、RTTY、SSTV 和 SSB，另有 Q65、MSK144、FST4、FST4W、JT65、JT9、JT4、JTTY、PSK31、PSK63 和 Olivia 作為實驗性模式。LQ8 是 HB9IPH 創建的弱訊號模式，只需四則訊息即可完成包含網格定位碼和訊號報告的 QSO。

qFT8 能搭配 POTA、SOTA、競賽和線上日誌使用嗎？

可以。它在地圖和電台列表中顯示 POTA 和 SOTA 的參考編號與即時 Spot，統計你的啟用 QSO 並匯出 ADIF；WWFF、IOTA、HEMA、GMA 等其他計畫，以及 ARRL Field Day 等競賽，均為實驗性。每個 QSO 在記錄時即可傳送到 QRZ、Logbook of the World、eQSL、Club Log、HRDLog、HamQTH、HAMLOG.online、Wavelog 或 Cloudlog，也可傳送到你網路中的日誌程式。

可以只用 qFT8 來收聽（SWL）嗎？

可以。qFT8 可以透過 SDR 接收機（Android 手機或 Linux 電腦上的 RTL-SDR 接收棒、網路上的 RTL-SDR 伺服器、自己的或公共的 KiwiSDR 以及其他網路 SDR）或處於 SWL 模式的一般電台接收並解碼它支援的所有模式；在 SWL 模式下它從不發射。你聽到的其他電台之間的 QSO 會記入收聽日誌，可匯出 SWL ADIF、CSV、SOTA SWL 和 RAZA SWL 檔案。使用手冊的 SWL 章節介紹了接收機及其驅動程式。

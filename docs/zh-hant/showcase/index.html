關於這些片段

每個片段都是合成的:由 qFT8 內建的編碼器產生,呼號是以數字 0 開頭的虛構呼號(沒有真實電台使用),圖片和旋律由我們自己的工具製作。這裡的內容都不是從空中接收的。在合適的情況下,一個片段會同時包含多個電台,就像真實的波段一樣。

定時模式會像空中一樣在 UTC 時隙開始:按下播放時,頁面會透過公共時間服務(timeapi.io 和 time.now,並以 cloudflare.com 做粗略檢查)校準時鐘,並顯示距離下一個時隙的倒數計時。如果都無法連線,則使用本裝置的時鐘並加以說明。

音量請適中:qFT8 在遠低於最大音量時也能很好地解碼這些片段。安靜的環境有助於慢速和寬頻模式。

片段很小(千位元組,而不是百萬位元組),因為只儲存訊號本身,使用 qFT8 自己的 .qft8 錄音格式。在 Android 手機或平板上,「在應用程式中開啟」會在 qFT8 中開啟片段(未安裝 App 時則儲存片段);在 iPhone 和電腦上會儲存片段,再由 qFT8 開啟儲存的檔案。

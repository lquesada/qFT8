Portable FT8, FT4, FT2, and JS8 for Android

Download .apk User Manual

Features

  • Quick setup
  • Supports 50+ radios
  • Supports FT8, FT4, FT2 and JS8 modes
  • Supports 30+ languages
  • Manual CALL mode and AUTO operation
  • Automatic NTP time synchronization
  • Automatic approximate location
  • ADIF logs import and export
  • Full QRZ integration
  • Full LotW integration
  • Retry logic with configurable limits
  • SOTA and POTA ADIF exports
  • Web server for fully-remote operation
  • Battery saving mode: runs with screen off

Download

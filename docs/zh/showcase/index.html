关于这些片段

每个片段都是合成的:由 qFT8 自带的编码器生成,呼号是以数字 0 开头的虚构呼号(没有真实电台使用),图片和旋律由我们自己的工具制作。这里的内容都不是从空中接收的。在合适的情况下,一个片段会同时包含多个电台,就像真实的波段一样。

定时模式会像空中一样在 UTC 时隙开始:点击播放时,页面会通过公共时间服务(timeapi.io 和 time.now,并用 cloudflare.com 做粗略校验)校准时钟,并显示距离下一个时隙的倒计时。如果都无法连接,则使用本设备的时钟并给出提示。

音量请适中:qFT8 在远低于最大音量时也能很好地解码这些片段。安静的环境有助于慢速和宽带模式。

片段很小(千字节,而不是兆字节),因为只保存信号本身,使用 qFT8 自己的 .qft8 录音格式。在 Android 手机或平板上,“在应用中打开”会在 qFT8 中打开片段(未安装应用时则保存片段);在 iPhone 和电脑上会保存片段,再由 qFT8 打开保存的文件。

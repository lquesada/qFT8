qFT8 奖状

内置于应用，面向业余无线电操作者和收听者（SWL）：为你通联或听到的模式、波段、DXCC 实体和网格方格授予星级，随进度逐步填满的奖状，以及可分享的成就。

应用会根据你自己的日志自动生成证书：无需申请，无需寄送。共有两个计划：HAM（已记录的通联）和 SWL（你收听到的电台）。

HAM 星级：14 种模式（FT8, LQ8, FT4, JS8, JT65, Q65, CW, SSB, FM, RTTY, PSK, SSTV, DV, JTTY）中的每一种和 13 个波段（160 米至 70 厘米）中的每一个，在 1, 5, 10, 50, 100, 500, 1000, 5000, 10000, 50000 个不同电台时最多可获得 10 颗星。DXCC 按 1 至 300 个现有实体（共 340 个）最多 10 颗星，网格方块按 1 至 2000 个最多 10 颗星。每个通联过的模式与波段组合再加一颗星：共 472 颗。

SWL：为你收听到的电台提供同样的星级，按业余模式分组、按业务（广播、时间信号、信标、海事、航空、气象）以及 DXCC 实体和网格方块计算。

无需确认：你的 qFT8 记录中的每个 QSO 都会计入，无论是否已确认，导入的也一样。你的 QSO 也会计入 SWL，连同你听到的每个电台，每个电台只算一次。

获取你的证书

  1. 打开设置：底部栏的齿轮按钮（在 Android、iPhone 和 iPad 上是最右边的按钮；在电脑上是底部栏中的齿轮），或网页遥控器中的齿轮标签页。
  2. 设置最上方有两个按钮，QSO 和 SWL，各有一颗星以及你已获得的星数。点按 QSO 或 SWL 按钮（在电脑上单击）即可打开它的证书；随着你记录和收听，证书会实时填满。
  3. 全屏：点按证书（在电脑和网页遥控器上单击）。双指捏合或鼠标滚轮可缩放，拖动可移动，双击会再次显示整页；退出按钮在右上角（在电脑上 Esc 也可关闭）。
  4. 分享：分享按钮位于证书上方那一行的最右端，或全屏视图的右上角。在 Android、iPhone 和 iPad 上会打开分享面板，证书以图片形式提供；电脑会将其保存为 PNG 文件；网页遥控器则会下载。证书语言按钮可选择证书绘制所用的语言。

常见问题

qFT8 是什么？

qFT8 是一款免费的业余无线电程序，支持弱信号数字模式、莫尔斯电码、电传、图片和语音。它可在 Android 手机和平板、iOS、Windows、macOS 和 Linux 上运行，并可通过任何浏览器控制。它没有广告，也无需账号。作者是 Luis Quesada Torres，HB9IPH，解码器和编码器均为自己从零编写。

为什么 qFT8 是 Android 上好用的 FT8 应用？

qFT8 是适用于 Android 6.0 及更高版本手机和平板的完整 FT8 电台：用一根 USB 线连接电台，qFT8 会自动识别并自行设置 CAT 和音频，无需电脑，也无需接口盒。它可收发 FT8、FT4、FT2、LQ8、JS8、WSPR 等模式，在完整 AUTO 下回应 CQ，通过互联网或 GPS 保持时钟准确，在实时世界地图上显示所有电台，并把每个 QSO 记录到你选择的服务中。熄屏后仍可继续运行。免费，无广告，无需账号。

我可以在 Windows、Mac 或 Linux 电脑上运行 qFT8 吗？

可以。qFT8 可在 Windows（64 位和 32 位，也可从 Microsoft Store 获取）、所有 Mac（Apple Silicon 和 Intel）以及 Linux（Intel/AMD 和 ARM，包括 Raspberry Pi）上运行，模式、电台和功能与 Android 版相同。本页的下载均免费。

有适用于 iPhone 和 iPad 的 qFT8 应用吗？

qFT8 也可在 iPhone 和 iPad（iOS）上运行。iPhone 或 iPad 无法通过线缆控制电台，因此它通过电台的 VOX，或通过可根据音频触发电台发射的音频接口来控制电台发射。

哪些电台可以配合 qFT8 使用？

70 多种电台型号可通过 USB 即插即用，包括 QRP Labs QMX、QMX+ 和 QDX，Icom IC-7300、IC-705 和 IC-9700，以及 Yaesu、Kenwood、Elecraft、Xiegu、Lab599、GuoHe、FlexRadio 和 (tr)uSDX 的电台。其他任何电台可通过 VOX 音频线或 DigiRig 使用，RTL-SDR 等 SDR 接收机可用于接收。

我能用手机配合 QRP Labs QMX 或 Icom IC-7300 吗？

可以。用一根 USB 线把 QMX、QMX+ 或 IC-7300 连接到 Android 手机或平板：qFT8 会找到电台，通过 CAT 读取和设置频率，并经同一根线收发音频。无需声卡或额外接口。电脑上同样可用。

qFT8 支持哪些模式？

FT8、FT4、FT2、LQ8、JS8、WSPR、CW、RTTY、SSTV 和 SSB，另有 Q65、MSK144、FST4、FST4W、JT65、JT9、JT4、JTTY、PSK31、PSK63 和 Olivia 作为实验性模式。LQ8 是 HB9IPH 创建的弱信号模式，只需四条消息即可完成包含网格定位码和信号报告的 QSO。

qFT8 能配合 POTA、SOTA、竞赛和在线日志使用吗？

可以。它在地图和电台列表中显示 POTA 和 SOTA 的参考编号与实时 Spot，统计你的激活 QSO 并导出 ADIF；WWFF、IOTA、HEMA、GMA 等其他计划，以及 ARRL Field Day 等竞赛，均为实验性。每个 QSO 在记录时即可发送到 QRZ、Logbook of the World、eQSL、Club Log、HRDLog、HamQTH、HAMLOG.online、Wavelog 或 Cloudlog，也可发送到你网络中的日志程序。

可以只用 qFT8 来收听（SWL）吗？

可以。qFT8 可以通过 SDR 接收机（Android 手机或 Linux 电脑上的 RTL-SDR 接收棒、网络上的 RTL-SDR 服务器、自己的或公共的 KiwiSDR 以及其他网络 SDR）或处于 SWL 模式的普通电台接收并解码它支持的所有模式；在 SWL 模式下它从不发射。你听到的其他电台之间的 QSO 会记入收听日志，可导出 SWL ADIF、CSV、SOTA SWL 和 RAZA SWL 文件。用户手册的 SWL 章节介绍了接收机及其驱动。

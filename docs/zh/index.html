功能特色

  • 免费且无广告
  • 即插即用 (Plug and Play)
  • 快速设置
  • 支持 75 多种电台
  • 支持 FT8、FT4、FT2 与 JS8 模式
  • 支持 30 多种语言
  • 手动 CALL 模式与 AUTO 自动运行
  • 自动 NTP 时间同步
  • 自动获取大致位置
  • ADIF 日志导入与导出
  • 完整集成 QRZ 日志
  • 完整集成 LoTW
  • 可配置次数的呼叫重试逻辑
  • SOTA 和 POTA 的 ADIF 导出
  • 支持全远程控制的内置 Web 服务器
  • 省电模式：可在熄屏下运行

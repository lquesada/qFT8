Android, iOS, Windows, macOS, Linux용 다중 모드 아마추어 무선

Android 휴대폰이나 태블릿, iPhone이나 iPad, 또는 Windows, macOS, Linux 컴퓨터를 완전한 디지털 모드 아마추어 무선국으로 바꿔 보세요. 무전기를 연결하고 CQ를 내고 전 세계와 교신하세요.

다운로드 사용자 설명서 qFT8 텔레그램 그룹 참여하기

주요 기능

  • 무료, 광고 없음, 계정 불필요
  • Android 휴대폰 및 태블릿, iOS, Windows, macOS, Linux
  • FT8, FT4, FT2, LQ8, Q65, MSK144, FST4, FST4W, JS8, WSPR, CW, RTTY, JTTY, SSTV, DRAW, SSB
  • 70개 이상의 무전기와 플러그 앤 플레이
  • 완전 AUTO 또는 원클릭 수동 호출
  • 실시간 스팟, POTA, SOTA, 밴드 전파를 보여 주는 라이브 세계 지도
  • 자유로운 사용자 지정
  • 연동: QRZ, Logbook of the World, Wavelog, Cloudlog, qFT8log, eQSL; ADIF, SOTA, POTA
  • 모든 브라우저에서 원격 제어
  • 37개 언어

특별한 감사 및 주요 기여자

Roger Ribes González (EA3ISA) — qFT8의 초기 개발 단계부터 아낌없는 지도와 긴밀한 협력, 광범위한 현장 베타 테스트를 통해 SOTA 및 POTA 기능을 구체화하는 데 크게 기여했습니다.

Andriy Dinets (UR4LBR) — 광범위한 베타 테스트와 스펙트로그램 렌더링, 디지털 신호 처리, SNR 정확도 및 SOTA/POTA 기능 향상과 관련된 복잡한 문제 해결에 결정적인 도움을 제공했습니다.

Rob Colclough (GW8RDI) — QuantumSDR 및 uSDX Open 프로젝트의 창립자이자 개발자입니다. 심도 있는 기술 자문과 헌신적인 테스트를 통해 qFT8이 여러 트랜시버와 다양한 Android 기기를 지원하는 데 중추적인 역할을 했습니다.
